# WISP

[English](README.md) · **Русский**

Самостоятельная защищённая панель WISP/NAT для **Xiaomi Router BE6500 RN02 с заводской MiWiFi 1.0.64**. Роутер получает интернет по Wi-Fi и раздаёт отдельную локальную сеть. Установка не включает WISP автоматически.

Поддержка других моделей, включая RD08, и других прошивок не подтверждена. Решение использует уже работающий штатный режим беспроводного повторителя. Прошивка и разблокировка не выполняются.

## Установка

1. Скачайте `WISP-0.6.0-Windows-installer.zip` из [релиза](https://github.com/defffis/WISP/releases/tag/v0.6.0) и распакуйте целиком.
2. Запустите `Install-WISP.bat`. Выберите `ru` или `en`: это язык установщика, панели и её сообщений. На роутер копируется только выбранный пакет локализации.
3. Укажите текущий IP роутера и порт SSH. Проверьте ключ SSH при первом подключении; пароль root вводится непосредственно в SSH.
4. Откройте `https://<IP-роутера>:8443/`. Вход: **root и текущий пароль SSH**. Локальный сертификат самоподписанный; сверяйте его через доверенное подключение.

Для установки из SSH: `sh install-wisp-0.6.0.sh ru` или `sh install-wisp-0.6.0.sh en`. Установщик проверяет SHA256, модель, прошивку, свободное место и состояние сети. Перед обычным обновлением выключите WISP. Установщик откажется обновлять активное подключение. Смена языка выполняется повторной установкой с выбранным языком.

Если прежняя установка WISP использует другую папку, сначала восстановите сеть и удалите её. Установщик запрещает параллельные установки.

## Использование

Нажмите **«Проверить возможность подключения»**, затем **«Включить WISP»**. Сеть изменится на **192.168.50.0/24**, панель — **https://192.168.50.1:8443/**. Переподключитесь к Wi-Fi, проверьте интернет и доступ к локальным устройствам, затем подтвердите подключение **в течение трёх минут**. Без подтверждения локальный процесс восстановит прежнюю сеть. Только подтверждение включает автозапуск после перезагрузки.

**«Выключить WISP»** возвращает штатный режим повторителя. **«Переподключить всех Wi-Fi-клиентов»** доступно и при включённом, и при выключенном WISP. Отключаются только клиенты двух локальных точек доступа; проводные устройства и Wi-Fi-соединение с основной сетью не затрагиваются. Клиент может сохранить прежний IP-адрес. Во время переключений эта операция недоступна.

**«Удалить WISP полностью»** доступно во всех состояниях. Требуется слово `УДАЛИТЬ` в русской панели или `DELETE` в английской. Сначала отключается автозапуск и восстанавливается исходная сеть, затем удаляются собственные файлы, задачи, ключ и журналы. При ошибке восстановления данные сохраняются для повторной попытки. В релизе также есть самостоятельный **`Uninstall-WISP.bat`**, работающий без панели и без загрузки кода из интернета.

## Безопасность и ограничения

Все страницы, локализация и API требуют авторизации. Изменяющие запросы дополнительно проверяют локальный адрес, Origin и CSRF. Сетевые UCI-файлы не записываются. Резервные снимки, журналы и сертификаты приватны; не публикуйте их.

Контроль проверяет STA, шлюз, адреса, маршруты, собственные правила, процесс DHCP/DNS и значимые настройки сети. Ночное расписание индикатора не вызывает откат. Недоступность панели сама по себе также не вызывает откат.

Поддерживается IPv4 и исходная LAN /24; IPv6 через WISP блокируется. Сложная маршрутизация не поддерживается. Доступ из интернета не предусмотрен. Решение использует системные nginx, OpenSSL, dnsmasq и BusyBox; дополнительные бинарники на роутер не устанавливаются.
